# Моё портфолио

Статический сайт-портфолио для курса "Программирование на Python 2026", собранный на MkDocs и опубликованный через GitHub Pages.

## Отчёт по лабораторной работе №1

### Цель

Освоить базовую настройку и публикацию статического сайта: структура страниц, навигация, сборка и развёртывание.

### Что сделано

1. Настроен проект MkDocs с исходниками в `source/docs` и генерацией сайта в `docs`.
2. Подготовлены страницы: главная, "О авторе", "Лабораторные работы".
3. Добавлены отдельные страницы лабораторных работ.
4. Настроена тема Dracula и базовые пользовательские стили.
5. Выполнена сборка и публикация сайта для доступа по публичной ссылке.

### Использованные технологии

- MkDocs
- Markdown
- Git и GitHub
- GitHub Pages

### Результат

Получен рабочий сайт-портфолио с навигацией и разделом лабораторных работ, доступный по публичному URL.

### Ссылки

- Репозиторий: https://github.com/RailMLearning/railmlearning.github.io
- Сайт: https://railmlearning.github.io

### Почему выбрана тема Dracula

Тема обеспечивает хороший контраст, удобную читаемость и аккуратный внешний вид для учебного портфолио с текстом и кодовыми фрагментами.

## Локальный запуск

```bash
mkdocs serve --dev-addr 127.0.0.1:8000
```

## Сборка

```bash
mkdocs build
```
