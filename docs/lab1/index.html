Лабораторная работа №1

Цель работы

Освоить создание статического сайта с использованием MkDocs и публикацию на GitHub Pages.

Задание

  • Создать структуру документации проекта.
  • Настроить MkDocs (mkdocs.yml, тема, навигация).
  • Выполнить сборку в каталог docs.
  • Опубликовать сайт через GitHub Pages.

Ход выполнения

  1. Создан репозиторий railmlearning.github.io.
  2. Инициализирован MkDocs-проект в каталоге source.
  3. Настроена тема dracula и меню навигации через nav.
  4. Созданы страницы: главная, об авторе, раздел лабораторных, страница лабораторной №1, шаблон отчёта.
  5. Выполнена сборка сайта в docs для публикации GitHub Pages.

Код и конфигурация

Ключевая команда сборки:

mkdocs build -d ../docs

Фрагмент mkdocs.yml:

site_name: Ягодный саверен
theme:
  name: dracula
nav:
  - Главная: index.md
  - Об авторе: about.md
  - Лабораторные работы: labs.md
  - Лабораторная работа №1: lab1.md
  - Шаблон отчёта: lab-template.md
  - Отчёт по лабораторной №1 (ссылки): lab1-report.md

Результат

Сформирован и опубликован статический сайт-портфолио на GitHub Pages.

  • Репозиторий: https://github.com/railmlearning/railmlearning.github.io
  • Сайт: https://railmlearning.github.io/labs/lab1/

Выводы

В ходе работы освоены базовые этапы разработки и публикации статического сайта: структурирование документации, настройка генератора MkDocs и развёртывание на GitHub Pages.
